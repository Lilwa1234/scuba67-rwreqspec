# Use Case Specification: UC10 - Generate Sales & Settlement Report

* **Use Case ID:** UC10[cite: 5]
* **Use Case Name:** ออกรายงานยอดขายและกระทบยอด (Generate Sales & Settlement Report)[cite: 5]
* **Actor หลัก:** เจ้าของร้าน / ผู้จัดการ (Owner / Manager)[cite: 5]
* **Pre-condition:** มีการทำรายการขายและทำการปิดกะประจำวันเรียบร้อยแล้ว[cite: 5]
* **Post-condition:** รายงานสรุปยอดขาย ยอดรับเงินโอน และค่าธรรมเนียมถูกสร้างขึ้นและพร้อมส่งออก[cite: 5]

## Main Flow (ลำดับขั้นตอนปกติ)
1. เจ้าของร้านเปิดหน้าต่าง "รายงานยอดขายและการเงิน" บนระบบ[cite: 5]
2. ระบุช่วงเวลาที่ต้องการดูข้อมูล (รายวัน, รายสัปดาห์, หรือรายเดือน)[cite: 5]
3. ระบบประมวลผลและแสดงยอดขายรวม จำแนกตามช่องทางชำระเงิน (เงินสด / QR Code), ค่าธรรมเนียมระบบ, ยอดรับสุทธิ และยอดตัดสต๊อก[cite: 5]
4. เจ้าของร้านกดปุ่มส่งออกรายงานในรูปแบบไฟล์ PDF หรือ Excel (.xlsx) เพื่อนำไปใช้งานด้านบัญชี[cite: 5]

## Alternative / Exception Flows (ขั้นตอนทางเลือก / กรณีข้อผิดพลาด)
* **3a. ยอดเงินไม่ตรงกับ Statement ธนาคาร:** เจ้าของร้านสามารถกดดูรายงาน "Discrepancy / Pending Log" เพื่อดูรายการที่อยู่ระหว่างการตรวจสอบของ Gateway ได้ทันที

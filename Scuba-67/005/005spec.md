# Use Case Specification: UC05 - Manage Menu & Modifiers

* **Use Case ID:** UC05[cite: 5]
* **Use Case Name:** จัดการเมนูและราคาตัวเลือก (Manage Menu & Modifiers)[cite: 5]
* **Actor หลัก:** เจ้าของร้าน / ผู้จัดการ (Owner / Manager)[cite: 5]
* **Pre-condition:** ผู้ใช้งานเข้าสู่ระบบด้วยสิทธิ์ผู้ดูแลระบบ (Admin Role)[cite: 5]
* **Post-condition:** ข้อมูลเมนู หมวดหมู่ และราคาตัวเลือกเสริมถูกปรับปรุงในฐานข้อมูลและพร้อมขายหน้าร้าน[cite: 5]

## Main Flow (ลำดับขั้นตอนปกติ)
1. เจ้าของร้านเปิดหน้าจอ "จัดการรายการสินค้า" บนระบบหลังบ้านหรือเครื่อง POS[cite: 5]
2. กำหนดรายละเอียดสินค้า ได้แก่ ชื่อเมนู, หมวดหมู่, และราคาเริ่มต้น[cite: 5]
3. ผูกกลุ่มตัวเลือกเสริม (Modifier Groups) เข้ากับเมนู พร้อมกำหนดราคาบวกเพิ่ม (เช่น ร้อน +0, เย็น +5, ปั่น +10)[cite: 5]
4. กดยืนยันการบันทึกข้อมูล[cite: 5]
5. ระบบซิงก์ข้อมูลเมนูและราคาไปยังหน้าจอขายหน้าร้านทันที[cite: 5]

## Alternative / Exception Flows (ขั้นตอนทางเลือก / กรณีข้อผิดพลาด)
* **2a. การลบเมนูถาวร:** หากเมนูเคยมีประวัติการขาย ระบบจะไม่อนุญาตให้ลบออกจากฐานข้อมูล แต่จะเปลี่ยนสถานะเป็น "ซ่อนเมนู" แทน เพื่อไม่ให้กระทบรายงานย้อนหลัง[cite: 5]

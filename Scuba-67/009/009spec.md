# Use Case Specification: UC09 - Operate Offline & Sync Data

* **Use Case ID:** UC09[cite: 5]
* **Use Case Name:** ใช้งานโหมดออฟไลน์และซิงก์ข้อมูล (Operate Offline & Sync Data)[cite: 5]
* **Actor หลัก:** แคชเชียร์ (Cashier), ระบบ (System Background Process)[cite: 5]
* **Pre-condition:** สัญญาณอินเทอร์เน็ตของร้านหลุดหรือไม่สามารถเชื่อมต่อคลาวด์ได้[cite: 5]
* **Post-condition:** การขายดำเนินต่อไปได้ และข้อมูลทั้งหมดถูกอัปโหลดขึ้นคลาวด์เมื่อกลับมาออนไลน์[cite: 5]

## Main Flow (ลำดับขั้นตอนปกติ)
1. ระบบตรวจพบสัญญาณอินเทอร์เน็ตขาดหาย และสลับเข้าสู่ "Offline Mode" โดยแสดงแถบสถานะสีส้มบนหน้าจอ[cite: 5]
2. แคชเชียร์สามารถรับออร์เดอร์ คิดเงินสด และสั่งพิมพ์ใบเสร็จได้ตามปกติ[cite: 5]
3. ระบบบันทึกข้อมูลธุรกรรมทั้งหมดไว้ใน Local Database ของเครื่อง POS[cite: 5]
4. เมื่อสัญญาณอินเทอร์เน็ตกลับมา ระบบจะทำการซิงก์ข้อมูลขึ้นคลาวด์ในพื้นหลัง (Background Sync) โดยอัตโนมัติ[cite: 5]
5. แถบสถานะเปลี่ยนกลับเป็นสีเขียว "Online" และข้อมูลยอดขายบนสมาร์ทโฟนของเจ้าของร้านอัปเดตตรงกันทันที[cite: 5]

## Alternative / Exception Flows (ขั้นตอนทางเลือก / กรณีข้อผิดพลาด)
* **4a. การซิงก์ข้อมูลล้มเหลว:** ระบบจะพยายามส่งข้อมูลซ้ำเป็นระยะ (Auto Retry ทุก 3 นาที) พร้อมแสดงสัญลักษณ์เตือนว่ามีข้อมูลที่ยังไม่ได้อัปโหลดค้างอยู่

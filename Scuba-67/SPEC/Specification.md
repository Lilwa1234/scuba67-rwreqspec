# Feature: การสั่งซื้อและชำระเงินด้วย Dynamic QR Code (Sales Ordering & Payment)
Spec ID: SPEC-POS-001 | Source: SRS v0.3 ข้อ 3.1 (FR-POS), ข้อ 3.3, ข้อ 3.4 | Use case: UC-01, UC-02, UC-03, UC-04, UC-06
Owner: ทีม POS Core | Status: Draft v1 | Updated: 2569-09-23

## Goal
พนักงานแคชเชียร์สามารถรับออร์เดอร์ เลือกตัวเลือกเมนู และรับชำระเงินผ่าน Dynamic QR Code ที่ล็อกยอดเงินได้อย่างถูกต้อง รวดเร็วภายใน 1 นาที พร้อมส่งรายการสั่งงานเข้าครัวอัตโนมัติ และแสดงสถานะยืนยันเงินเข้าแบบเรียลไทม์เพื่อขจัดปัญหาเงินค้างในระบบ

## Scope
### In scope
- หน้าจอขายหน้าร้าน (POS Grid), การเลือกตัวเลือกเสริม (Modifiers: ร้อน/เย็น/ปั่น)
- สลับสถานะสินค้าหมด (Sold-out Toggle) ได้ทันทีจากหน้าจอขาย
- ส่งพิมพ์ใบแจ้งงานครัว (Kitchen Order Ticket: KOT) ผ่านเครือข่ายภายในร้าน
- สร้าง Dynamic PromptPay QR Code ล็อกยอดเงินตามบิลแสดงบนจอลูกค้า
- รับ Webhook ยืนยันเงินเข้าเรียลไทม์ และแสดงฟีดรายการเงินเข้า (Transaction Feed) พร้อมปุ่ม Re-check
### Out of scope
- การผูกสูตรตัดสต๊อกอัตโนมัติ (UC-07) และการบันทึกของเสีย (UC-08)
- การสรุปรายงานภาษีและบัญชีประจำเดือน (UC-10)
- การเข้าสู่ระบบและจัดการสิทธิ์ผู้จัดการร้าน (ถือเป็น Precondition ที่ทำสำเร็จแล้ว)

## Constraints
- CON-TECH-01 ใช้ SQLite/IndexedDB บนเครื่อง POS หน้าร้านเป็นฐานข้อมูลหลัก เพื่อรองรับการขายต่อเนื่องแบบ Offline
- CON-HW-01 รองรับเครื่องพิมพ์ใบสั่งงานครัวผ่านพอร์ต LAN (TCP/IP) ด้วยโปรโตคอล ESC/POS
- IF-PAY-01 เชื่อมต่อ Payment Gateway ด้วย REST API สำหรับสร้าง Dynamic QR Code และรับผลการชำระเงินผ่าน Webhook
- DOM-FIN-01 บันทึก Transaction Log ของการชำระเงินทุกรายการ (Order ID, Bank Ref, Amount, Gateway Timestamp) เก็บไว้ไม่น้อยกว่า 90 วัน
- IF-NOT-01 ส่งสัญญาณอัปเดตสถานะเงินเข้าและสถานะสินค้าหมดไปยังเครื่องอื่นๆ ผ่าน WebSocket แบบ Asynchronous

## Requirements
- FR-POS-01 ระบบต้องรองรับการเลือกเมนูและตัวเลือกเสริม (Modifiers) พร้อมคำนวณราคาสุทธิแบบเรียลไทม์
- FR-POS-02 ระบบต้องอนุญาตให้สลับสถานะเมนูเป็น "สินค้าหมด" (Sold Out) ได้ทันทีจากหน้าจอขาย โดยไม่ต้องสลับแอปพลิเคชัน   <- UC-06
- FR-POS-03 เมื่อกดยืนยันคำสั่งซื้อ ระบบต้องส่งข้อมูลพิมพ์ใบสั่งงานครัว (KOT) ผ่านเครือข่าย Local LAN โดยอัตโนมัติ           <- UC-02
- FR-POS-04 ระบบต้องสร้าง Dynamic PromptPay QR Code ที่ระบุยอดเงินสุทธิของบิล เพื่อแสดงบนหน้าจอฝั่งลูกค้า                    <- UC-03
- FR-POS-05 เมื่อ Payment Gateway ส่งสัญญาณยืนยันเงินเข้า ระบบต้องอัปเดตสถานะ "สำเร็จ" ปิดบิล และบันทึก Transaction Log ทันที <- UC-03, UC-04
- FR-POS-06 หากระบบไม่ได้รับสัญญาณยืนยันเงินเข้าภายใน 3 นาที ระบบต้องแสดงสถานะ "รอยืนยัน" พร้อมปุ่มกด Re-check สถานะธุรกรรม     <- UC-03 exception 5a

## Quality Requirements
- NFR-PERF-01 เวลาตอบสนองต่อการสัมผัสหน้าจอ (Touch Latency): p95 <= 0.5 วินาที
- NFR-PERF-02 ทำรายการตั้งแต่เลือกเมนูจนออกใบเสร็จเสร็จสิ้นภายในเวลาไม่เกิน 1 นาที
- NFR-SEC-01 สัญญาณ Webhook จาก Payment Gateway ต้องได้รับการตรวจสอบ Signature (HMAC-SHA256) ทุกครั้ง
- NFR-REL-01 เมื่อสัญญาณอินเทอร์เน็ตขัดข้อง ระบบต้องยังคงเปิดบิล รับเงินสด และพิมพ์ใบเสร็จในโหมด Offline ได้

## Acceptance Criteria
- [ ] AC-POS-01 (FR-POS-04, FR-POS-05)
      Given สรุปยอดบิล 125 บาท
      When  เลือกชำระด้วย QR Code
      Then  ระบบแสดง Dynamic QR ยอด 125 บาท และเมื่อเงินเข้า หน้าจอเปลี่ยนสถานะเป็นสำเร็จและปิดบิลภายใน 3 วินาที
- [ ] AC-POS-02 (FR-POS-02)
      Given เมนูชานมเย็นวัตถุดิบหมด
      When  แคชเชียร์กดค้างที่รูปเมนูและเลือก "สินค้าหมด"
      Then  ปุ่มเมนูเปลี่ยนเป็นสีเทา ติดป้าย "หมด" และไม่สามารถกดสั่งลงตะกร้าได้
- [ ] AC-POS-03 (FR-POS-03)
      Given ยืนยันคำสั่งซื้อหน้าร้าน
      When  กดยืนยันบิล
      Then  เครื่องพิมพ์ครัวพิมพ์ใบ KOT ที่มีรายการเมนูและตัวเลือกเสริมออกภายใน 2 วินาที
- [ ] AC-POS-04 (FR-POS-06)
      Given ลูกค้าสแกนจ่ายแต่สัญญาณ Webhook ล่าช้าเกิน 3 นาที
      When  ครบกำหนดเวลา Timeout
      Then  หน้าจอแสดงสถานะ "รอยืนยัน" และแสดงปุ่ม Re-check ให้แคชเชียร์กดตรวจสอบยอดจาก Gateway ได้โดยตรง
- [ ] AC-POS-05 (NFR-REL-01)
      Given เครื่อง POS ไม่มีสัญญาณอินเทอร์เน็ต
      When  ทำรายการขายด้วยเงินสด
      Then  ระบบบันทึกรายการขายลง Local DB ออกใบเสร็จได้ปกติ และซิงก์ขึ้นคลาวด์เมื่อเน็ตกลับมา
- [ ] AC-POS-06 (DOM-FIN-01)
      Given รายการชำระเงินผ่าน QR Code สำเร็จ
      When  ทำรายการเสร็จสิ้น
      Then  มี Transaction Log ที่ระบุ Order ID, Bank Ref ID, ยอดเงิน และเวลา บันทึกอยู่ในระบบ

## Assumptions & Open Questions
- ASM-01 หน้าจอฝั่งลูกค้า (Customer Display) เชื่อมต่อเป็นจอที่สองผ่านสายสัญญาณหรือแท็บเล็ตในวง LAN เดียวกัน
- ASM-02 อัตราค่าธรรมเนียม Gateway ถูกหักรอบบัญชีปลายทาง ไม่นำมาแสดงหักในสลิปของลูกค้า
- Q-01 กรณีลูกค้าโอนสำเร็จแต่เงินค้างในระบบ Gateway แคชเชียร์สามารถกด "อนุมัติออร์เดอร์ชั่วคราวพร้อมแนบภาพสลิป" ได้เลยหรือไม่ หรือต้องให้ผู้จัดการใส่รหัส PIN? -> ถามพี่เบิร์ด (เจ้าของร้าน)
- Q-02 รายการเครื่องดื่มประเภท "ปั่น" ต้องแยกพิมพ์ออกใบแจ้งงานไปที่เคาน์เตอร์บาร์น้ำต่างหากหรือไม่? -> ถามพนักงานหน้าร้าน

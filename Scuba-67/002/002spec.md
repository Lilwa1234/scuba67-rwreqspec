# Use Case Specification: UC02 - Send Order to Kitchen

* **Use Case ID:** UC02[cite: 5]
* **Use Case Name:** ส่งรายการเข้าครัว (Send Order to Kitchen)[cite: 5]
* **Actor หลัก:** แคชเชียร์ (Cashier)[cite: 5]
* **Actor รอง:** พนักงานครัว (Kitchen Staff)[cite: 5]
* **Pre-condition:** คำสั่งซื้อได้รับการยืนยันจากหน้าจอแคชเชียร์เรียบร้อยแล้ว[cite: 5]
* **Post-condition:** ข้อมูลรายการอาหารแสดงบนหน้าจอครัว (KDS) หรือพิมพ์ออกมาเป็นใบแจ้งงานครัว (KOT)[cite: 5]

## Main Flow (ลำดับขั้นตอนปกติ)
1. เมื่อแคชเชียร์กดยืนยันออร์เดอร์ ระบบส่งข้อมูลคำสั่งซื้อผ่านเครือข่ายภายในร้าน (Local LAN) ไปยังห้องครัวโดยตรง[cite: 5]
2. เครื่องพิมพ์ครัวพิมพ์ใบแจ้งงานครัว (Kitchen Order Ticket: KOT) หรือหน้าจอ KDS แสดงรายการพร้อมเลขออร์เดอร์[cite: 5]
3. พนักงานครัวตรวจสอบรายการ ตัวเลือกเสริม และเริ่มเตรียมอาหารตามลำดับคิว[cite: 5]

## Alternative / Exception Flows (ขั้นตอนทางเลือก / กรณีข้อผิดพลาด)
* **1a. การเชื่อมต่อเครื่องพิมพ์ครัวขัดข้องหรือกระดาษหมด:** ระบบที่หน้าจอ POS จะแสดงแถบแจ้งเตือนสีแดง "พิมพ์ใบครัวล้มเหลว" พร้อมปุ่มกดสั่งพิมพ์ซ้ำ (Reprint) เมื่อแก้ไขปัญหาเสร็จสิ้น[cite: 5]

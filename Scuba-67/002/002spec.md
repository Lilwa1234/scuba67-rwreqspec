# Use Case Specification: UC02 - Send Order to Kitchen

* **Use Case ID:** UC02[cite: 5]
* **Use Case Name:** ส่งรายการเข้าครัว (Send Order to Kitchen)[cite: 5]
* **Status:** Draft v2
* **วันที่อัปเดต:** 2026-10-01
* **Actor หลัก:** แคชเชียร์ (Cashier)[cite: 5]
* **Actor รอง:** พนักงานครัว (Kitchen Staff)[cite: 5]
* **Pre-condition:** คำสั่งซื้อได้รับการยืนยันจากหน้าจอแคชเชียร์เรียบร้อยแล้ว และพร้อมจะส่งข้อมูลเข้าครัวผ่านระบบ Local LAN[cite: 5]
* **Post-condition:** ข้อมูลออร์เดอร์ถูกส่งผ่าน Local LAN ไปยังระบบ Print Queue และแสดงผลที่หน้าจอ KDS หรือพิมพ์ออกใบแจ้งงานครัว (KOT) ตามสถานีเตรียมงานที่กำหนดไว้ โดยข้อมูลออร์เดอร์ไม่สูญหาย และหากพิมพ์ล้มเหลว ระบบจะแสดงแถบแจ้งเตือนสีแดงที่หน้าจอ POS[cite: 5]

## Main Flow (ลำดับขั้นตอนปกติ)
1. เมื่อแคชเชียร์กดยืนยันคำสั่งซื้อ ระบบส่งข้อมูลออร์เดอร์ทันทีผ่านเครือข่ายภายในร้าน (Local LAN) ไปยังระบบ Print Queue และประมวลผลพิมพ์ใบครัวภายใน 2 วินาที[cite: 5]
2. ระบบ Print Dispatcher จัดรูปแบบข้อมูลตามสถานีเตรียมงานที่กำหนดไว้ แล้วส่งไปแสดงผลบนหน้าจอ KDS หรือสั่งพิมพ์ออกใบแจ้งงานครัว (KOT) พร้อมเลขออร์เดอร์และข้อมูลเมนูที่ครบถ้วน[cite: 5]
3. พนักงานครัวตรวจสอบรายการ ตัวเลือกพิเศษ (Modifiers) และเริ่มเตรียมอาหารตามลำดับคิว โดยเรียงตามลำดับเวลาที่กดยืนยันคำสั่งซื้อและหมายเลขออร์เดอร์ที่ส่งเข้ามา[cite: 5]

## Alternative / Exception Flows (ขั้นตอนทางเลือก / กรณีข้อผิดพลาด)
* **1a. การเชื่อมต่อระบบส่งงานครัวขัดข้องหรือเครื่องพิมพ์ครัวขัดข้อง:** ระบบที่หน้าจอ POS จะแสดงแถบแจ้งเตือนสีแดง "พิมพ์ใบครัวล้มเหลว" ทันที โดยข้อมูลออร์เดอร์ไม่สูญหาย และพนักงานสามารถกดปุ่ม "Reprint KOT" ได้เมื่อต่อเชื่อมต่อสำเร็จ[cite: 5]

## Assumptions (ข้อสมมติฐานจากคำตอบของทีม)
- **ASM-01:** ออร์เดอร์ถูกส่งทันทีหลังแคชเชียร์กดยืนยันคำสั่งซื้อผ่าน Local LAN และต้องประมวลผลพิมพ์ออกภายใน 2 วินาที (Q1)
- **ASM-02:** หากระบบส่งงานครัวขัดข้อง หน้าจอ POS จะแสดงแถบแจ้งเตือนสีแดง "พิมพ์ใบครัวล้มเหลว" ทันที และข้อมูลออร์เดอร์ต้องไม่สูญหาย พร้อมให้กดปุ่ม "Reprint KOT" เมื่อเชื่อมต่อสำเร็จ (Q2)
- **ASM-03:** ระบบส่งข้อมูลผ่าน Local LAN ไปแสดงผลบน KDS หรือสั่งพิมพ์ KOT โดยมี Print Dispatcher จัด Format ตามสถานีเตรียมงานที่กำหนดไว้ (Q3)
- **ASM-04:** ลำดับคิวจัดเรียงตามลำดับเวลาที่กดยืนยันคำสั่งซื้อ และหมายเลขออร์เดอร์ที่ส่งเข้ามา (Q4)
- **ASM-05:** ออร์เดอร์ที่ยืนยันแล้วจะถูกส่งไปครัวทันที หากต้องส่งข้อมูลใหม่ แคชเชียร์สามารถกดปุ่ม "พิมพ์ใบครัวซ้ำ (Reprint KOT)" จากหน้ารายละเอียดออร์เดอร์ (Q5)
- **ASM-06:** KOT/KDS ต้องระบุเลขออร์เดอร์, ชื่อรายการเมนู, และตัวเลือกพิเศษ (Modifiers) อย่างครบถ้วนชัดเจน (Q6)

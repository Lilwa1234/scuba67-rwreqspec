# Use Case Specification: UC08 - Record Waste & Staff Meals

* **Use Case ID:** UC08[cite: 5]
* **Use Case Name:** บันทึกของเสียและอาหารพนักงาน (Record Waste & Staff Meals)[cite: 5]
* **Actor หลัก:** แคชเชียร์ (Cashier), เจ้าของร้าน / ผู้จัดการ (Owner / Manager)[cite: 5]
* **Pre-condition:** เกิดของเสีย ชงผิด หก หรือพนักงานทำเครื่องดื่มรับประทานเอง[cite: 5]
* **Post-condition:** สต๊อกวัตถุดิบถูกตัดออก และบันทึกต้นทุนเป็นค่าใช้จ่ายภายใน ไม่กระทบยอดขายจริง[cite: 5]

## Main Flow (ลำดับขั้นตอนปกติ)
1. ผู้ใช้งานเลือกฟังก์ชัน "บันทึกตัดสต๊อกภายใน / ของเสีย" บนระบบ POS[cite: 5]
2. เลือกรายการเมนูหรือวัตถุดิบที่เสียหาย หรือนำไปใช้ภายใน[cite: 5]
3. ระบุเหตุผลในการตัดยอด (เช่น ชงผิด, วัตถุดิบหมดอายุ, สวัสดิการพนักงาน)[cite: 5]
4. กดยืนยันการตัดสต๊อก[cite: 5]
5. ระบบหักยอดคงเหลือของวัตถุดิบ และบันทึกข้อมูลลงรายงานต้นทุนสูญเสีย (Loss & Waste Report)[cite: 5]

## Alternative / Exception Flows (ขั้นตอนทางเลือก / กรณีข้อผิดพลาด)
* **1a. กำหนดสิทธิ์การตัดของเสีย:** หากเปิดระบบรักษาความปลอดภัย ระบบจะร้องขอรหัส PIN ของผู้จัดการก่อนกดยืนยันการตัดของเสีย

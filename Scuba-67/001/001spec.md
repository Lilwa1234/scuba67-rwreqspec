# Use Case Specification: UC01 - Manage Sales Order

* **Use Case ID:** UC01[cite: 5]
* **Use Case Name:** จัดการคำสั่งซื้อหน้าร้าน (Manage Sales Order)[cite: 5]
* **Actor หลัก:** แคชเชียร์ / พนักงานหน้าร้าน (Cashier)[cite: 5]
* **Actor รอง:** ลูกค้า (Customer)
* **Pre-condition:** แคชเชียร์เข้าสู่ระบบและทำการเปิดกะการขายเรียบร้อยแล้ว[cite: 5]
* **Post-condition:** คำสั่งซื้อถูกสร้างในระบบ ยอดเงินรวมถูกคำนวณ และพร้อมสำหรับขั้นตอนการส่งต่อหรือชำระเงิน[cite: 5]

## Main Flow (ลำดับขั้นตอนปกติ)
1. แคชเชียร์เลือกหมวดหมู่สินค้าและกดเลือกรายการเมนูตามความต้องการของลูกค้า[cite: 5]
2. แคชเชียร์เลือกตัวเลือกเสริม (Modifiers) เช่น ระดับความหวาน, ขนาดแก้ว, หรือรูปแบบร้อน/เย็น/ปั่น[cite: 5]
3. ระบบคำนวณราคาต่อหน่วยและยอดรวมสะสมแบบเรียลไทม์[cite: 5]
4. แคชเชียร์ทวนรายการออร์เดอร์กับลูกค้า และกดยืนยันคำสั่งซื้อ[cite: 5]

## Alternative / Exception Flows (ขั้นตอนทางเลือก / กรณีข้อผิดพลาด)
* **1a. ยกเลิกหรือปรับลดรายการก่อนยืนยัน:** แคชเชียร์สามารถปัดลบรายการหรือแก้ไขจำนวนได้ทันทีก่อนการกดยืนยันบิล[cite: 5]
* **2a. ตัวเลือกหมดระหว่างสั่ง:** หากตัวเลือกย่อยหมด ระบบจะแสดงสัญลักษณ์ปิดตัวเลือกนั้น และไม่อนุญาตให้กดเลือก

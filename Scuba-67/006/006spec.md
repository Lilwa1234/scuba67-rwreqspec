# Use Case Specification: UC06 - Toggle Sold-Out Status

* **Use Case ID:** UC06[cite: 5]
* **Use Case Name:** สลับสถานะสินค้าหมดด่วน (Toggle Sold-Out Status)[cite: 5]
* **Actor หลัก:** แคชเชียร์ (Cashier)[cite: 5]
* **Pre-condition:** มีวัตถุดิบหมดกะทันหันในระหว่างวัน[cite: 5]
* **Post-condition:** เมนูดังกล่าวถูกปิดใช้งานบนหน้าจอขาย และไม่สามารถสั่งซื้อได้[cite: 5]
* **Status:** Draft v2
* **Last Updated:** 2026-10-03

## Main Flow (ลำดับขั้นตอนปกติ)
1. แคชเชียร์กดค้าง 1 วินาทีบนปุ่มการ์ดรูปภาพเมนูที่ต้องการบนหน้าจอขายหน้าร้าน เพื่อเปิดหน้าต่างสวิตช์ด่วน (Quick Action Toggle)[cite: 5]
2. แคชเชียร์เลือกสลับสวิตช์สถานะเป็น "สินค้าหมด (Sold Out)" สำหรับเมนูที่ตรงกับรหัสรายการ `{id}` ที่เลือกเท่านั้น โดยไม่กระทบเมนูอื่นโดยอัตโนมัติ[cite: 5]
3. ระบบจะปิดใช้งานเมนูที่เลือกบนหน้าจอขายของเครื่อง POS ทุกเครื่องทันที โดยไม่ให้คลิกสั่งซื้อได้ และส่งสัญญาณ WebSocket Broadcast ไปยังแอปพลิเคชันของเจ้าของร้านทันที[cite: 5]
4. ปุ่มเมนูดังกล่าวเปลี่ยนเป็นสีเทาและแสดงป้ายข้อความ "หมด" ทันที โดยไม่ต้องสลับไปใช้งานแอปอื่น[cite: 5]

## Alternative / Exception Flows (ขั้นตอนทางเลือก / กรณีข้อผิดพลาด)
* **2a. วัตถุดิบพร้อมขายอีกครั้ง:** แคชเชียร์กดค้างที่เมนูเดิม 1 วินาที และกดสลับสวิตช์กลับเป็น "พร้อมขาย" เมนูจะกลับมาสั่งซื้อได้ตามปกติทันทีโดยไม่ต้องรอการอนุมัติเพิ่มเติม[cite: 5]

## Assumptions (สมมติฐาน)
* **ASM-01:** การปิดสถานะจะใช้กับเมนูที่เลือกเท่านั้นตามรหัสรายการ `{id}` และไม่ปิดเมนูอื่นโดยอัตโนมัติ[cite: 5]
* **ASM-02:** ผลของการปิดสถานะมีผลต่อหน้าจอขายของเครื่อง POS ทุกเครื่อง และทำให้คลิกสั่งซื้อไม่ได้ทันที[cite: 5]
* **ASM-03:** การกดค้าง 1 วินาทีบนปุ่มการ์ดรูปภาพเมนูจะเปิด Quick Action Toggle เพื่อให้สลับสถานะได้ทันที[cite: 5]
* **ASM-04:** เมื่อแคชเชียร์สลับกลับเป็น "พร้อมขาย" ระบบจะคืนสถานะเมนูเป็นปกติทันที พร้อมให้กดสั่งซื้อได้ทันทีโดยไม่ต้องรอการอนุมัติ[cite: 5]
* **ASM-05:** การปิดสถานะนี้เป็นการปิดชั่วคราวระหว่างวันหน้าร้าน จนกว่าแคชเชียร์จะกดค้างเพื่อสลับกลับเป็น "พร้อมขาย" อีกครั้งเมื่อวัตถุดิบพร้อม[cite: 5]
* **ASM-06:** ส่วนหลังบ้านจะใช้ WebSocket Broadcast เพื่อซิงก์ข้อมูลไปยังเครื่อง POS ทุกเครื่องแบบเรียลไทม์ เพื่ออัปเดตสถานะเมนูให้ตรงกันทุกเครื่อง[cite: 5]
